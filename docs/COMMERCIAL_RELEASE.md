# Commercial release
Professor Pro $12/month: 10-file local batch studio, HTML reading drafts, findings JSON, CSV summary, optional tagged draft PDF archive, private cloud review summaries. Institution $79/month: same workflow, 30 files per member per batch, organization-wide subscription entitlement, role-based membership and centralized owner billing. The free single-file checker remains free. No managed remediation, shared documents, certification or arbitrary monthly usage quotas are advertised. No new third-party paid dependency. Customers pay only after explicitly confirming Paddle checkout. Existing Paddle email-authenticated portal and receipts remain the management mechanism. The server enforces cloud storage entitlements; local browser batch UI is an ergonomic feature, not a claim of tamper-proof browser DRM. Private test checkout must be closed at launch. Production activation is a separate release gate after automated and live smoke checks.
