# Paddle lifecycle integration
Customer created/updated events fetch canonical customer status without storing payment details or email. Subscription catalog mirrors customer, price, product, exact status, scheduled action and effective date. Access remains active during scheduled cancellation until provider changes status; active and unexpired trialing access, past_due grace, paused/canceled revoked, adjustment holds override. Plan changes within the supported ownership scope are mirrored; personal-to-institution or institution-to-personal changes are recorded and access held until an explicit owner-verified scope transfer. Do not bypass that check. The existing passkey-only identity cannot safely establish exclusive ownership of a Paddle customer-wide authenticated portal; the receipt-based portal remains the supported route until verified identity linking is implemented. Migration 0007 and production webhook deployment are required. No money collected by this change.
