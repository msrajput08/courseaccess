# Verified plan assignment
A change of catalog plan is detected from canonical Paddle items. A personal account that becomes an institution must explicitly choose an organization it owns. An institution that becomes Professor Pro is assigned to its current owner after recent passkey verification. The database guards source ownership, target ownership, catalog version, refund holds, other subscriptions and pending checkouts in an atomic batch. No provider charges or API changes are made by this assignment. Automatic guessing of an organization is prohibited. The signed lifecycle integration test covers both transfers, unauthorized users, duplicate transaction events, and grant/revocation.
