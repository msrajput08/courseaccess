# Private live verification
The seller retrieves the private discount from Paddle Catalog > Discounts, signs in to CourseAccess, and opens the private owner billing verification section. The server validates the exact single-use 100% recurring discount, checks the transaction preview is zero, reserves a single draft, and opens the Paddle default payment page. Public paid checkout remains disabled. A real card is entered only by the seller in Paddle; verify the checkout displays zero today and on renewal before confirmation. The signed webhook only grants test cloud-summary access if a verified test intent and zero transaction total match. Cancel immediately from the same account after checking access and archive the discount in Paddle. No code or checkout link is printed in public GitHub Actions logs.
