# Paid feature release gate
Production routes now expose authenticated entitlement status, a guarded checkout intent endpoint and optional numeric cloud history. New purchases and paid access remain disabled in the production configuration. No paid cloud data is collected until activation. The browser-local remediation features remain free; the current server-backed cloud history alone does not fulfill the proposed paid plans. Do not enable paid checkout before additional institution functionality and a complete provider-side lifecycle test. Manual schema installations are audited separately from migration ledger tracking. No owner action is required to run these code checks.
